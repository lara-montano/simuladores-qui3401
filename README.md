# Simuladores de Equilibrio Químico (QUI3401)

Nueve simuladores interactivos para el curso **Termodinámica del Equilibrio Químico**:
valle de Gibbs, criterio Q contra K, reformado de metano, Debye–Hückel y efecto salino,
Maxwell–Boltzmann y Arrhenius, tabla ICE, relación K = k_f/k_r, orden de reacción y
extracción entre fases.

**Ábrelos aquí:** https://lara-montano.github.io/simuladores-qui3401/

Cada simulador es una sola página HTML, sin dependencias ni conexión a servicios
externos: funciona en el teléfono y en la computadora, y también sin internet si se
descarga el archivo.
